# 1.1.0

- Added a saved language selector: German, English, French, Spanish, Italian, Portuguese and Japanese.
- Localized Kanso settings, tray actions, group editor, counts and common status/error messages. Native Windows menus follow the Windows language.
- Named the release executable and assembly KansoDesktop.exe / KansoDesktop.
- Preserved Windows startup, restoration, accepted group appearance and existing references.
- Improved readable checkbox labels and wrapping of translated buttons.

Inline renaming, positioning at the release point, full accessibility and further reboot/monitor/long-running scenarios remain documented limitations.
